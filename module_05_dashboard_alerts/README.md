# Module 05 – Dashboard & Alerts

**Run:** `python app.py`
**Access:** http://<raspberry-pi-ip>:5000

Features:
- Live MJPEG camera stream
- Real-time heart rate and temperature display
- Fall alert status and popup
- Manual robot control (direction pad)
- Activity log
- Demo fall simulation button

**Test Telegram:** `python telegram_bot.py`
